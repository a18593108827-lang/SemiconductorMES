# Design System Master

> **Source of truth:** 仓库根目录 `DESIGN.md` + `PRODUCT.md`  
> 页面细则：`docs/UI/MES-UI设计.md`  
> 本文件仅作索引；实现以 `DESIGN.md` token 为准，勿使用下方过时自动生成色板。

## Dual theme

| 场景 | 主题 |
|---|---|
| 管理端 / 工程师 | Admin Light |
| 现场 Track / EDC | Field Dark |
| 投屏看板 | Field Dark 或看板壳 |

## Page overrides

按需在 `design-system/mes/pages/<page>.md` 写偏离 Master 的规则；未写则完全遵循 `DESIGN.md`。
