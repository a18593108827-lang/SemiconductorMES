## 16. 行业特化（按需）

### 电子组装 / SMT
- SMT 上料防错、Feeder 管理
- SPI / AOI / ICT / FCT 数据集成
- PCB 条码、Panel 拆拼板
- 锡膏 / 胶水时效管控

### 半导体 / 晶圆
- Lot / Wafer / Die 多级追溯
- Recipe / Chamber 管控
- 光罩、FOUP 载体管理
- 洁净室、人员进出联动
- AMHS 自动物流

### 汽车零部件
- IATF 16949、APQP、PPAP
- 关键次件追溯、防错防呆
- 序列号 / VIN 关联
- 产线 JIS/JIT 排序供料

### 医药 / 医疗器械
- GMP、21 CFR Part 11
- eBMR / eDHR
- 批记录、偏差、变更控制
- 环境温湿度联动

### 离散机加 / 重工
- 数控程序 DNC 下发
- 刀具寿命管理
- 工序外协
- 大件序列号装配

## 大厂常见优先级（建设顺序）

1. **主数据 + 工单执行 + 过站追溯**（必须有）
2. **质量检验 + 不良闭环**
3. **线边物料防错 + 叫料**
4. **设备状态 / OEE / 安灯**
5. **数采与自动化对接**
6. **SPC / 电子批记录 / 合规**
7. **APS 细排程 + 多厂协同 + 分析看板**
