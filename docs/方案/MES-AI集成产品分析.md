> 定位：站在产品角度回答「集成 AI 能做什么、先做什么、什么做不了」；供分期决策
> 更新：2026-09-18

## 1. 核心结论（先看这个）

1. **大厂 AI 落地最成熟的场景，恰好是本 MES 已规划的场景**：良率检控 → 建议 Hold 闭环、EDC/SPC 智能判异、异常根因辅助。国内 12 寸厂（晶合集成 × 智现未来）已验证可行。
2. **2025 年的新增量是 LLM/Agent，不是传统 ML**：大厂与工业软件商（PDF Solutions、Spotfire、应用材料）都在转向「自然语言查数 + Agentic 分析 + 人机协同（AI 提议、人决策）」。本项目的 Agent 数据暴露规划（2026-09-18 立项）正好踩在这个趋势上，应作为一切 AI 功能的**第一块地基**。
3. **硬边界**：预测性维护（PdM）、虚拟量测（VM）、RL 派工等大厂主打场景，依赖**设备传感器数据（数采/FDC）**——本项目数采后置，短期内做不了。不要为了对齐大厂而提前堆模型。
4. **产品原则已被业界反复验证**：AI proposes, human decides（建议制、可驳回、可审计、HITL）。与现有方案「AI 不直接改 Lot 状态」完全一致，坚持即可。

|----|-----------|----------------|
| 应用材料 SmartFactory | **CIM 集成 AI 平台**：预测类（周期、动态瓶颈、良率预测）+ 优化类（控制参数寻优）；收购 minds.ai（RL）做自主工厂 | AI 平台与 MES 同源集成（不外挂）；模型自动训练/部署/监控闭环；6 个月交付周期是卖点 |

| Spotfire Copilot | 分析平台内嵌 LLM：自然语言生成/修改图表、AI 解读图表、RAG 引用文档 | Copilot 形态（人开车、AI 辅助）是工程师分析场景的标配方向 |
| 智现未来（国内） | 灵犀大模型 + 晶合集成落地：WRA 晶圆溯因 + YPA 良率预测；PM Agent（健康画像/预警/自动派单/动态 SOP）；智能配方优化器（反向推算参数） | 缺陷分类 1 小时 → 1 秒；报告编制 1 天 → 1 分钟；自动 Hold / OOC 处理 24h 内闭环；维护成本 -30%；调参 35 轮 → 8 轮 |

### 2.3 共性规律（重要）

1. **收益集中在三类**：a) 异常→拦截的时间压缩（检测/分类/报告提速 10x~3600x）；b) 非计划停机减少 30%+；c) 周期与产能（派工/调度优化 10%~15%）。
2. **没有任何大厂让模型裸改状态**：全部走「建议 → 人工确认（或白名单 + 审计）」。
3. **数据是分水岭**：传感器级数据（FDC/Trace）在手才有 PdM/VM；只有 MES 事务数据就先做检控与知识类。**这决定了本项目的取舍**。

## 3. 本 MES 现状 × AI 能力地图

已有数据资产：`mes_tx_log`（全事务）、EDC 手录点 + Spec 判定、SPC 控制图、Alarm、Hold、History 调查台、Report（Move/Hold）、Dispatch 规则。
缺失：设备传感器数据（数采后置）、量测文件/缺陷图、片级 Wafer、ERP 工单。

### 3.1 按用户角色看 AI 价值

| 角色 | 痛点 | AI 能做什么 | 不做什么 |
|------|------|-------------|----------|
| 现场操作员 | 3 步过站，看不懂长报表 | Alarm/拒出时给**一句人话**的原因与下一步（引 SOP 步骤） | 不加确认弹窗、不嵌聊天窗打断过站 |
| 工艺/设备工程师 | 排查靠翻多张表；报告手写；经验在脑子里 | 根因摘要、相似案例检索、NL 查数、班报/客诉包自动起草 | 不替工程师下结论定责 |
| 班组长/管理 | 看板要人去「读」 | 看板自动旁白（Top 异常、Hold 趋势解读）；日报推送 | 不做真 OEE / Yield 顶卡（与 Dashboard 定位一致） |

### 3.2 能力分层（依赖 × 收益）

| 层 | 能力 | 依赖 | 大厂对标 | 判断 |
|----|------|------|----------|------|
| L0 | Agent 数据暴露（Tool Facade + 可选 MCP） | 无（纯架构） | PDF Solutions 用 MCP | **已立项，P0，一切的前提** |
| L1 | NL 查数 Copilot（「在制有多少」「这批卡在哪」） | L0 | Spotfire Copilot | 快赢：复用 Report/WIP/History Facade |
| L1 | 班报/周报/客诉追溯包**摘要生成** | L0 + History | 智现未来（报告 1 天→1 分钟） | 快赢：把后置的「客诉包」升级为「AI 客诉包」亮点 |
| L1 | 知识助理 RAG（K0 案例库起步） | L0 | Spotfire RAG 引用 | 已有方案，照 K0→K4 走 |
| L1 | Alarm/Hold 根因摘要（拉上下文→LLM→引用来源） | L0 + History | 智现未来 WRA | 性价比高；先摘要后诊断 |
| L2 | 良率检控（统计基线→L1/L2 告警→建议 Hold） | 良率宽表 | 智现未来自动 Hold 闭环；AMAT 预测 | 已有方案 A→C；验收卡在误报率 |
| L2 | EDC/SPC 智能判异增强 | L2 数据 | AMAT NG-FDC | SPC 硬门槛不动，AI 只做增强层 |
| L2 | 相似 Lot 根因检索 | L2 | PDF 多 Agent 诊断的简化版 | 与 RAG 分区展示 |
| L3 | Dispatch 打分增强 | L2 模型 | 台积电 AI 派工（远期 RL） | 规则否决权高于模型（已定） |
| L3 | 设备健康预警 / PdM | **数采 + FDC（未建设）** | 台积电/AMAT/智现未来 PM Agent | **被依赖阻塞，勿提前启动** |
| L3 | 虚拟量测 VM | 数采 + EDC 扩展 | Intel VMSS | 同上 |
| L3 | 智能配方优化 | RMS + 工艺数据积累 | 智现未来反向推算 | 远期 |

## 4. 产品决策建议

| # | 决策 | 建议 | 理由 |
|---|------|------|------|
| D1 | AI 第一批交付 | **L0 + L1 全家**：Agent 数据暴露 → NL 查数 → 报告生成 → RAG K0 | 依赖少、可见度高、不动主路径；2~3 个月可出 demo 级价值 |
| D2 | 第二批 | L2 良率检控 A→C（统计起步，建议 Hold 闭环） | 大厂验证最充分的场景；本 MES 的 EDC/Alarm/Hold 管道已齐 |
| D3 | 数采与 AI 的关系 | 数采立项时**同步预留 AI 特征管道**（Trace 原始数据落 OLAP），但 PdM/VM 在数采稳定前不启动 | 避免为模型预建空转数据链 |
| D4 | 客诉追溯包 | 与 L1 摘要生成合并交付「AI 追溯包」：履历 + EDC + Hold 拉齐 → LLM 起草 + 人工确认 | 把 History 后置项变成 AI 时代的差异化卖点 |
| D5 | 前端形态 | 工程师侧：全局 Copilot + Alarm/Hold/Lot 侧栏「问 AI」；现场侧：只读提示，不加交互负担 | 对齐三角色画像 |
| D6 | 度量 | 上线即定 KPI：查数耗时、报告编制耗时、异常→Hold 确认时长、误报率 | 大厂口径可参照（分类 1h→1s、报告 1d→1min） |

**禁止**

| # | 禁止 | 理由 |
|---|------|------|
| P1 | 为对齐大厂提前做 PdM / VM / RL 派工 | 数采未建，无米之炊；空转数据链 |
| P2 | LLM 直写 Lot 状态 / Hold / Recipe | 违反状态唯一真相（与既有方案一致） |
| P3 | 把 Copilot 塞进现场过站路径 | 现场 3 步 Track 是成功标准，不许打扰 |
| P4 | 跳过 L0 直接堆 AI 功能 | 无 Tool Facade 的审计/限流，治理失控 |
| P5 | 用云 LLM 处理未脱敏工艺数据 | 机密与合规 |

## 6. 风险

| 风险 | 对策 |
|------|------|
| NL 查数产出错误数字 | 只查只读 Facade；结果附 SQL/来源；权限走 Sa-Token 原权限码 |
| LLM 幻觉进报告 | 强制引用（RAG 方案已定）；报告标注「AI 起草·待确认」 |
| 知识库冷启动 | K0 先案例模板 + 录入流程，案例 < 50 条不上向量 |
| 误报 Hold 招投诉 | 建议制起步；白名单灰度（AI 赋能方案 L4 已定） |
| 云/私有 LLM 选型摇摆 | 先定脱敏网关边界，模型可替换；接口层不绑死厂商 |

---

## 7. 结论

**先 Agent（数据暴露 + Copilot + 报告 + RAG K0），再检控（良率→建议 Hold），后重模型（等数采）。**
大厂已验证的收益区间（分类/报告 10x~3600x 提速、停机 -30%、周期 -15%）中，本项目 12 个月内可兑现的是前两类；第三类是数采之后的故事。产品叙事：**「工程师的 AI 助手」先立住，「自主工厂」是远期愿景**——与业界「AI proposes, human decides」共识一致。
