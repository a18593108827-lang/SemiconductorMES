## 1. 核心结论（先看这个）

1. **建议主定位：后道封测（OSAT），聚焦功率器件 / SiC 这类车规场景。** 本系统的内核——Track 事务唯一真相 + Lot 谱系正反向追溯 + Hold 拦截 + EDC/SPC 判异 + 客诉追溯包（CP-1～CP-6）——正好是后道 MES 的三大重心「批次流转 + 正反向追溯 + 质量拦截」。
2. **前道不是「多做几个模块」的问题**：入场券是 8–9 个子系统的 CIM 全家桶（MES+EAP+RTD+APC+FDC+RMS+YMS+SPC+RCM）协同交付，且 **MES 仅占 CIM 系统成本约 15%**；叠加「一旦启用就不能更换」的试错壁垒。
3. **12 寸量产线不列入近期目标。** 若将来做前道，唯一现实入口是 8 寸 / 特色工艺（功率、MEMS、化合物半导体）——这类厂国产化程度较高，且常与封测同厂（SiC 为典型衔接）。

## 3. 前道 vs 后道：需求差异（业务口径）

### 3.1 后道封测的三大硬骨头

| # | 硬骨头 | 说明 |
|---|--------|------|
| 1 | **追溯颗粒度：从「片」到「颗」** | 要追到 die 级甚至封装体级——哪颗来自哪片 wafer 的哪个位置，出问题精准召回而不是整批报废 |
| 2 | **CP/FT 测试分档数据海量回流** | 每颗测了什么、分了哪个 Bin，要与批次绑定；这是晶圆段没有的量级 |
| 3 | **换型频繁** | 多品种小批量（今天 QFN、明天 BGA），配方与排产要跟得上，否则产能全耗在调机 |

**客户审厂是最硬的痛点**：大客户要求 **15 分钟内提供任意批次的全流程追溯数据**；车规按 **IATF 16949 / VDA 6.3 / AEC-Q** 审，现状多为 Excel 与纸质（有案例：一次审厂抽调 3 人忙两周）。→ **这正是客诉追溯包（含 ZIP 证据链）的靶心。**

### 3.2 前道的规模与实时性要求

- 单片上千道工序（另有「约 300 道」口径）、在制 >10000 批、设备数百种；驻留时间（Q-Time）约束严格，调度失误可能整批报废（单次数百万元级损失）。
- EAP 需毫秒级采集，每秒处理数千至上万条设备消息；Recipe 数量可达数十万，版本管理是独立难题。
- **RTD 是真正的技术分水岭**：毫秒级调度本质是「柔性作业车间 + 重入工艺 + 驻留时间约束」的强 NP 难问题；业界评价「MES 各家功能差距有限，RTD 才拉开差距」。
- 国产化现状：4–6 寸已基本国产化 / 8 寸国外占一半以上 / 12 寸几乎全垄断（AMAT SmartFactory、IBM SiView 等），且**替换壁垒是「不敢换」**（良率降 0.5% 即单季数亿元损失），12 寸国产仍处「单点尝试或方案阶段」。

## 4. 开发难度对比

| 维度 | 前道 Fab | 后道封测 |
|------|----------|----------|
| 子系统数量 | **8–9 个必须齐**（MES+EAP+RTD+APC+FDC+RMS+YMS+SPC+RCM）；MES 仅占 CIM 成本约 15% | 4–6 个，**可分期** |
| 实时性 | RTD 毫秒级、EAP 万条/秒级 | 秒—分钟级可接受 |
| 数据规模 | 上千工序 / 万批在制 / 数十万 Recipe | 工序短、Batch 与 Strip/Die 数量大，痛点在换型与测试数据 |
| 设备接入 | SECS/GEM 刚需 + 私有扩展适配，数百机型协议库 | 设备种类少；**STDF 文件 / 扫码批记录可过渡**，SECS/GEM 后置 |
| 人才要求 | 需懂工艺的复合型（头部国产厂商积累 20+ 年；「纯软件人才远远不够」） | 相对可得 |
| 试错成本 | **「一旦启用就不能更换」**，客户宁可多花钱买国外大厂 | 可分段上线，可与 Excel 并行过渡 |
| 客户决策 | 倾向单一供应商全栈 +（国内）关注供应链安全 / 国资背书 | 可点状采购、分步验收 |
| 交付方式 | 平台级整体替换，周期以年计 | 单线 / 单模块起步，可按产线推广 |

**一句话**：前道 = 交付一个平台生态；后道 = 交付一套能用起来的执行系统。

## 5. 与本系统的匹配度对账

| 能力 | 现状 | 前道要求 | 后道要求 |
|------|------|----------|----------|
| Lot 事务与谱系 | ✅ Track 唯一真相 + Split/Merge 正反向 | 需要，且要叠加片级 / SlotMap | **核心命中** |
| Route / 版本快照 | ✅ 已落地 | 上千工序、复杂重入与分支 | 够用（多品种换型需加强排产 / 配方切换） |
| Hold / 拦截 | ✅ 含 Future Hold | 需要 | **核心命中**（不良 Bin → Hold/Rework） |
| EDC / SPC / Alarm | ✅ 手录 + Spec 门禁 + 判异 + 实时告警 | 需 APC/FDC 增强 | 够用，可作 SPC 前置拦截 |
| 追溯 / 客诉 | ✅ History 调查台 + 客诉包（影响面 + 履历 + 遏制 + JSON/ZIP 证据） | 需片级与工艺参数级 | **现成卖点**：审厂 / 8D / 召回证据链 |
| 设备接入 | ⚠️ 仅主数据 + 手动选机，Adapter 后置 | **EAP（SECS/GEM）刚需** | 可先用文件 / API / 扫码过渡 |
| 片级 / 载具 | ❌ 无片级、无 SlotMap、无 FOUP/OHT | **刚需** | 不需要（改用 Die / Strip / Tray 层级） |
| 测试数据 | ❌ 无 CP/FT、无 Bin | 不适用（WAT/CP 属前道侧） | **需补**：测试结果 + Bin 定义 + 不良映射 |
| 调度 | ⚠️ 候选 / 推荐 + Reserve | **RTD 毫秒级刚需** | 规则级够用（换型排产可后补 APS） |

**后道需补（是「扩展」不是「重写」）**：Die / Strip / Tray 层级、测试程序与 Bin 结果回流、不良 Bin → Hold/Rework 联动、客户 Lot 映射（来料 wafer lot → 封装 lot → 出货 lot）、颗级序列号追溯、出货 / 编带、委外工序（划片 / 电镀 / 测试外协）、轻量 YMS / OEE。

**明确不做（前道入场费，后道用不到）**：SlotMap / FOUP / OHT-AMHS / Reticle / APC / FDC / 全量 RMS / 毫秒级 RTD。

## 6. 分期建议（已采纳后道定位）

```
第一批（封测最小闭环）—— 对应 INT-0001
  Die / Strip / Tray 层级 + 客诉包延伸到颗级
  → 测试数据回流（STDF / CSV 文件起步）+ Bin 定义
  → 不良 Bin → Hold / Rework 联动
第二批（质量与效率）
  QMS 轻量（IQC/IPQC/OQC 检查点）+ OEE（设备状态已在手）
  → 换型排产 / 配方切换防错
第三批（对接与出货）
  委外工序管理 + 出货 / 编带 + 客户 Lot 映射
  → EAP 试点（先测试机 / 分选机，SECS/GEM 或文件）
并行（差异化，不抢主线）—— 对应 INT-0002
  AI：L0 Agent 数据暴露 → L1「AI 客诉摘要」/ 自然语言查数（见 MES-AI集成产品分析.md）
```
