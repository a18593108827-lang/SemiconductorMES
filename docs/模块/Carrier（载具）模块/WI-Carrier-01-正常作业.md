# WI-Carrier-01 载具正常作业

> 版本：v1 · 适用系统：MES 薄 Carrier（Car-1～5）  
> Owner：工艺 / 制造工程（填写姓名）______  
> 培训：上线前 15 分钟 + 一次实操

---

## 1. 目的

保证过站批次始终挂在明确载具上，避免「货在哪个盒」不清。

## 2. 适用范围

- 试点产线 / 产品族：______（开闸前填）
- 入口：`/app/carrier` 载具台账；`/app/lots` 批次详情；`/track` 现场过站

## 3. 状态说明（现场用语）

| 状态 | 意思 | 能否绑 Lot |
|------|------|------------|
| 空闲 AVAILABLE | 可使用 | 能 |
| 使用中 IN_USE | 已挂 Lot | 不能再绑别的 Lot |
| 隔离 QUARANTINE | 异常扣留 | 不能 |
| 报废 SCRAPPED | 终态 | 不能 |

## 4. 正常步骤

### 4.1 新建载具（有 `carrier:edit`）

1. 打开「载具台账」→「新建载具」
2. 填「载具编码」（与实物标签一致，如 `FOUP-A-001`）
3. 类型默认 FOUP；容量按实物（常见 25）
4. 创建成功后状态为「空闲」

### 4.2 绑定（有 `carrier:bind`）

**时机：** Lot 放行后、**首次 TrackIn 前**必须完成（试点开闸后系统强制）。

任选一种入口：

**A. 从载具**  
载具详情 → 填「批次 ID」→「绑定」

**B. 从批次**  
批次详情「载具」→ 填「载具编码 / ID」→「绑定」

成功后：盒变「使用中」；Track 上可见载具码。

### 4.3 TrackIn 开工

1. 现场选 Lot，确认「载具」列有码（非「—」）
2. 选设备 → Track In / 开工
3. 若试点已开闸且未绑：系统拒绝（见 WI-02）

### 4.4 换盒

1. 解绑旧盒（盒侧或批侧均可）
2. 再绑新盒  
**禁止**在已绑状态下直接绑另一只盒（系统会报已绑定）。

### 4.5 解绑（盒回收）

**时机：** Lot 完工出站盒回收、或明确不再用该盒时。

1. 确认无未完成的「必须带盒」工序约定（按线别补充）
2. 「解绑」→ 盒回「空闲」；批次载具清空

### 4.6 隔离 / 报废（有 `carrier:edit`）

1. 先解绑（使用中不能手改态）
2. 详情「改态」→ 隔离 或 报废  
报废不可恢复为生产用盒。

## 5. 检查（班前 30 秒）

- [ ] 本班将过站的 Lot 是否都已绑盒  
- [ ] 实物标签码与系统「载具号」一致（目视；扫码比对后置）  
- [ ] 隔离/报废盒未出现在生产绑用清单  

## 6. 相关配置

- `mes.carrier.enabled=true`（模块开）
- `mes.carrier.track-in-required`：试点线 true，其它线默认 false
