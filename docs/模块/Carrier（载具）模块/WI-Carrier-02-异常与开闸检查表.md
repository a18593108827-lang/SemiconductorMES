# WI-Carrier-02 载具异常处理与开闸检查表

> 版本：v1 · 与 WI-01 配套  
> 回滚电话 / 值班：______  

---

## 1. 常见异常

| 现象 | 系统表现 | 处理 |
|------|----------|------|
| 未绑就开工（闸已开） | 拒绝，提示须绑定载具 / `CARRIER_REQUIRED` | 按 WI-01 绑定后再 In |
| Lot 已绑别的盒 | `LOT_ALREADY_BOUND` | 先解绑再绑目标盒 |
| 盒已被别的 Lot 占用 | `CARRIER_ALREADY_BOUND` | 换空闲盒，或先解对方（需权限与班长确认） |
| 隔离/报废盒想绑 | 状态不允许 | 换空闲盒；隔离盒勿生产 |
| 使用中无法改态 | 提示先解绑 | 解绑后再改隔离/报废 |
| 并发抢绑失败 | 并发/冲突类错误 | 刷新后重试；以系统结果为准 |
| 盒显示使用中但无 Lot | 数据异常（孤儿盒） | 班长+工程：在台账对该盒再绑收回或解绑清理；记异常单 |
| 模块关闭 | `CARRIER_DISABLED` | 找 IT 查 `mes.carrier.enabled` |

## 3. 回滚

1. 将 `mes.carrier.track-in-required` 改回 `false` 并发布  
2. 通知试点班组：闸已关，仍按纪律绑盒  
3. 保留拒闸与异常记录，分析后再开  

## 4. 升级

以下情况升级工程 + IT，勿反复盲操作：

- 同一 Lot/盒反复绑失败  
- 怀疑系统与实物长期不一致  
- 需全厂开闸或改权限模型
